# rodrigoalvarez.me

Static website of Rodrigo Álvarez Consulting S.L.U., served with GitHub Pages.

- `index.html` — home page
- `legal/index.html` — legal notice
- `404.html` — not-found page
- `assets/` — styles, self-hosted fonts (Inter, Manrope) and a small script for the "Contact via Email" button
- `CNAME` — custom domain for GitHub Pages

No build step, no cookies, no analytics, no third-party requests.
